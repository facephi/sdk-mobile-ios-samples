# Facephi SDK Mobile samples

In this repository are the programming examples for using the Facephi Mobile SDK.

[SDK Mobile documentation](https://docs.facephi.com/sdks/sdk-mobile/ios-sdk)

| Demo | Description |
|------|-------------|
| `DemoOnboardingFileUploader` | Onboarding with Selphi, SelphID, Capture and VideoRecording, plus file upload. |
| `DemoOnboarding` | Classic onboarding: Selphi and SelphID with Tracking, Tokenize and Status. |
| `DemoRecordingOnboarding` | Classic onboarding with Selphi, SelphID and VideoRecording. |
| `DemoIDV` | IDV onboarding driven by a backend flow (Selphi, SelphID, VideoRecording, Tracking). |
| `DemoNFC` | Document capture with SelphID and NFC chip reading. |
| `DemoPhingers` | Fingerprint capture with Phingers. |
| `DemoSelphiClassic` | Facial capture with Selphi Classic. |
| `DemoSelphi` | Facial capture with Selphi. |
| `DemoSelphIDClassic` | Document capture with SelphID Classic. |
| `DemoSelphID` | Document capture with SelphID. |
| `DemoVideoCall` | Video call with screen sharing. |
| `DemoVideoId` | Video capture with VideoID. |
| `DemoVoice` | Voice capture with VoiceID. |
