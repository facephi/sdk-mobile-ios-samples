# Facephi SDK Mobile samples

In this repository are the programming examples for using the Facephi Mobile SDK.

[SDK Mobile documentation](https://docs.facephi.com/sdks/sdk-mobile/ios-sdk)

| Demo | Description |
|------|-------------|
| `onboarding-fileuploader.demo` | Onboarding with Selphi, SelphID, Capture and VideoRecording, plus file upload. |
| `sdkmobile-demo-classic-pods` | Classic onboarding: Selphi and SelphID with Tracking, Tokenize and Status. |
| `sdkmobile-demo-classic-videorcording.pods` | Classic onboarding with Selphi, SelphID and VideoRecording. |
| `sdkmobile-demo-idv` | IDV onboarding driven by a backend flow (Selphi, SelphID, VideoRecording, Tracking). |
| `sdkmobile-demo-nfc-pods` | Document capture with SelphID and NFC chip reading. |
| `sdkmobile-demo-phingers-pods` | Fingerprint capture with Phingers. |
| `sdkmobile-demo-selphi-classic-pods` | Facial capture with Selphi Classic. |
| `sdkmobile-demo-selphi-pods` | Facial capture with Selphi. |
| `sdkmobile-demo-selphid-classic-pods` | Document capture with SelphID Classic. |
| `sdkmobile-demo-selphid-pods` | Document capture with SelphID. |
| `sdkmobile-demo-signature-pods` | Digital signature with Selphi and VideoID (Tokenize, Status, Tracking). |
| `sdkmobile-demo-videocall-pods` | Video call with screen sharing. |
| `sdkmobile-demo-videoid` | Video capture with VideoID. |
| `sdkmobile-demo-voiceid-pods` | Voice capture with VoiceID. |
