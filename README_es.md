# Facephi SDK Mobile samples

En este repositorio se encuentran los ejemplos de programación para usar el SDK Mobile de Facephi.

[Documentación del SDK Mobile](https://docs.facephi.com/sdks/sdk-mobile/ios-sdk)

| Demo | Descripción |
|------|-------------|
| `onboarding-fileuploader.demo` | Onboarding con Selphi, SelphID, Capture y VideoRecording, con subida de ficheros. |
| `sdkmobile-demo-classic-pods` | Onboarding clásico: Selphi y SelphID con Tracking, Tokenize y Status. |
| `sdkmobile-demo-classic-videorcording.pods` | Onboarding clásico con Selphi, SelphID y VideoRecording. |
| `sdkmobile-demo-idv` | Onboarding IDV dirigido por un flujo del backend (Selphi, SelphID, VideoRecording, Tracking). |
| `sdkmobile-demo-nfc-pods` | Captura de documento con SelphID y lectura del chip NFC. |
| `sdkmobile-demo-phingers-pods` | Captura de huellas con Phingers. |
| `sdkmobile-demo-selphi-classic-pods` | Captura facial con Selphi Classic. |
| `sdkmobile-demo-selphi-pods` | Captura facial con Selphi. |
| `sdkmobile-demo-selphid-classic-pods` | Captura de documento con SelphID Classic. |
| `sdkmobile-demo-selphid-pods` | Captura de documento con SelphID. |
| `sdkmobile-demo-signature-pods` | Firma digital con Selphi y VideoID (Tokenize, Status, Tracking). |
| `sdkmobile-demo-videocall-pods` | Videollamada con compartición de pantalla. |
| `sdkmobile-demo-videoid` | Captura de video con VideoID. |
| `sdkmobile-demo-voiceid-pods` | Captura de voz con VoiceID. |
