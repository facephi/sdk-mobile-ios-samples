# Facephi SDK Mobile samples

En este repositorio se encuentran los ejemplos de programación para usar el SDK Mobile de Facephi.

[Documentación del SDK Mobile](https://docs.facephi.com/sdks/sdk-mobile/ios-sdk)

| Demo | Descripción |
|------|-------------|
| `DemoOnboardingFileUploader` | Onboarding con Selphi, SelphID, Capture y VideoRecording, con subida de ficheros. |
| `DemoOnboarding` | Onboarding clásico: Selphi y SelphID con Tracking, Tokenize y Status. |
| `DemoRecordingOnboarding` | Onboarding clásico con Selphi, SelphID y VideoRecording. |
| `DemoIDV` | Onboarding IDV dirigido por un flujo del backend (Selphi, SelphID, VideoRecording, Tracking). |
| `DemoNFC` | Captura de documento con SelphID y lectura del chip NFC. |
| `DemoPhingers` | Captura de huellas con Phingers. |
| `DemoSelphiClassic` | Captura facial con Selphi Classic. |
| `DemoSelphi` | Captura facial con Selphi. |
| `DemoSelphIDClassic` | Captura de documento con SelphID Classic. |
| `DemoSelphID` | Captura de documento con SelphID. |
| `DemoVideoCall` | Videollamada con compartición de pantalla. |
| `DemoVideoId` | Captura de video con VideoID. |
| `DemoVoice` | Captura de voz con VoiceID. |
